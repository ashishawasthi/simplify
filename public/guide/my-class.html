My class

A page from the student's class teacher or coach, one screen at a time. It opens without internet too.

Add the class to this device 🔗

  1. Scan the class's QR code with the camera.
  2. The app asks Is this your class? Check the name, and tap ✔ Yes.

Or type the code: on the set-up page, under My class at the top, type the 9 letters and numbers printed under the QR code. There is no button to press.

iPad or iPhone with Simplify on the Home Screen? The camera opens the QR code in Safari, not in the app. So type the code in the app instead: open Simplify from the Home Screen, tap ℹ️ How to use this app, then Set up this device.

Read the page 🔗

  • Tap My class at the top of the menu.
  • Next ▶ shows the next screen, ◀ Back the one before. ✔ All done on the last screen goes back to the menu.
  • With internet, the app looks for a new page now and then, and each time My class opens. Without internet, it shows the copy it saved.
  • A video from the coach never plays by itself. Tap ▶.
  • Nothing from your coach yet: the class has no page yet.

To change or leave the class: the set-up page, My class, then Change or Leave.

What it sends 🔗

To get the page, the app sends only the class code — and, like any website, the device's internet address. Nothing the student types or taps is sent.

A YouTube video shows as a card: Watch on YouTube (needs the internet). Nothing loads from YouTube until someone taps it. After the tap, YouTube (Google) gets the device's internet address and which video is watched.
